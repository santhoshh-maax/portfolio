Road Bot - AI Powered Autonomous Rover

An autonomous engineering solution designed to detect and repair road damage in real-time. Utilizing YOLOv8 computer vision and Intel RealSense depth sensing, the rover identifies potholes, calculates exact volumetric repair requirements, and deploys a custom screw-conveyor mixing system for precise concrete application.

Smart Toilet Monitoring System

Developed an ESP32-based IoT Smart Toilet System that automates sanitation using PIR and Ultrasonic sensors. Integrated Real-time Humidity Control and Gas Leakage (Smoke) Detection with a Telegram Bot interface for remote monitoring, manual overrides, and an automated user-complaint registration system.

Github Repo

Hand Gesture Controlled LED System using MediaPipe & ESP32

Developed a Hand Gesture Controlled LED System using MediaPipe, OpenCV, and ESP32 that recognizes real-time hand gestures through a webcam and controls LEDs via serial communication for touchless IoT interaction.

RAG Chatbot using MongoDB Atlas, Ollama, LangChain, and FastAPI

A Retrieval-Augmented Generation (RAG) chatbot built using MongoDB Atlas Vector Search, Ollama, Gemma 3, LangChain, and FastAPI. The application retrieves relevant information from a vector database and generates context-aware responses using a locally hosted Large Language Model (LLM).
